= Saiba mais sobre a virtualização Red Hat OpenShift
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
O Red Hat® OpenShift Virtualization permite que as organizações migrem, executem e gerenciem máquinas virtuais (VMs) tradicionais juntamente com cargas de trabalho modernas em uma plataforma de aplicativos de nuvem híbrida unificada. OpenShift Virtualization está disponível como um operador incluído em qualquer assinatura OpenShift. Este complemento para a OpenShift Container Platform fornece uma solução robusta para integrar VMs com aplicativos em contêineres. Ele usa o Kernel-based Virtual Machine (KVM), o hipervisor confiável do kernel Linux, conhecido por desempenho robusto, escalabilidade e estabilidade, para fornecer virtualização de nível empresarial para máquinas virtuais como objetos nativos dentro do OpenShift.

image:redhat-openshift-044.png["Virtualização OpenShift"]



[[key-features-of-red-hat-openshift-virtualization]]
== Principais características da virtualização Red Hat OpenShift

**Cargas de trabalho híbridas:** Migre e execute VMs com os benefícios nativos da nuvem, gerenciando-as juntamente com contêineres e cargas de trabalho sem servidor usando um conjunto de ferramentas unificado.

**Modernização gradual:** Modernize no seu próprio ritmo, adotando contêineres, implementando microsserviços ou integrando IA, sem interromper as VMs existentes.

**Integração com Kubernetes:** Utiliza recursos personalizados do Kubernetes para adicionar funcionalidades de virtualização ao seu OpenShift cluster.



[[capabilities-of-red-hat-openshift-virtualization]]
== Recursos da virtualização Red Hat OpenShift

**Gerenciamento de VMs:** Crie e gerencie VMs Linux e Windows.

**Cargas de trabalho unificadas:** Execute cargas de trabalho de pod e VM simultaneamente dentro de um cluster.

**Conectividade:** Acesse as VMs por meio de vários consoles e ferramentas de linha de comando.

**Operações de VM:** importar, clonar e migrar VMs em tempo real entre nós.

**Gerenciamento de recursos:** Gerencie interfaces de rede e discos de armazenamento conectados às máquinas virtuais.



[[compatibility]]
== Compatibilidade

Embora a OpenShift Virtualization difira conceitualmente do VMware vSphere, ela oferece uma plataforma moderna feita sob medida para administradores de virtualização, com funcionalidades familiares, como: **Migração ao vivo:** equivalente ao vMotion no vSphere.

**Gerenciamento de armazenamento:** As classes de armazenamento em OpenShift estão alinhadas com o Storage Policy Based Management (SPBM) em vSphere.

**Storage Persistente:** Persistent Volume Claims (PVC) e Persistent Volumes (PV) correspondem a Datastores em vSphere.
