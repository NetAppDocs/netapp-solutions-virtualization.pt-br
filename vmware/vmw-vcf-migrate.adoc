= Saiba mais sobre como convergir um ambiente vSphere com datastores existentes para um domínio de gerenciamento VCF
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Qualquer ambiente vSphere compatível pode ser integrado a um ambiente de nuvem privada VCF. Ele pode ser convergido para um domínio de gerenciamento VCF ou importado como um domínio de carga de trabalho. Esta solução demonstra como os datastores VMFS ou NFS existentes em vSphere se tornam o storage primário quando o cluster é convertido para um domínio de gerenciamento VCF.



[[solution-overview]]
== Visão geral da solução

Esta solução demonstra como os datastores VMFS ou NFS existentes em vSphere se tornam o storage primário quando o cluster é convergido para um domínio de gerenciamento VCF.

Esse processo se beneficia da robustez e flexibilidade do armazenamento ONTAP para garantir acesso e gerenciamento de dados contínuos. Após o estabelecimento de um domínio de gerenciamento VCF por meio do processo de convergência, os administradores podem importar com eficiência ambientes adicionais do vSphere, incluindo aqueles que usam datastores VMFS e NFS, para o ecossistema VCF.

Essa integração não apenas melhora o uso de recursos, mas também simplifica o gerenciamento da infraestrutura de nuvem privada, garantindo uma transição suave com interrupção mínima nas cargas de trabalho existentes.



[[architecture-overview]]
== Visão geral da arquitetura

A arquitetura das ferramentas ONTAP integra-se perfeitamente aos ambientes VMware, aproveitando uma estrutura modular e escalável que inclui os serviços das ferramentas ONTAP , o plug-in vSphere e as APIs REST para permitir gerenciamento de armazenamento eficiente, automação e proteção de dados.

As ONTAP tools for VMware vSphere podem ser instaladas em configurações HA ou não HA.
