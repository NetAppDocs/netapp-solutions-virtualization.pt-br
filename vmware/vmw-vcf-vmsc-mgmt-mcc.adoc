[role="lead"]
Neste caso de uso, descrevemos o procedimento para configurar um cluster estendido para o domínio de gerenciamento do VMware Cloud Foundation (VCF) usando o ONTAP MetroCluster com FC, iSCSI, NVMe-oF, NFSv3 ou NFSv4.1 como datastore primário. O VCF oferece flexibilidade nas opções de implantação com base nas suas necessidades. A ferramenta VCF Installer é usada para implantar um novo domínio de gerenciamento do VCF ou converter um ambiente vSphere existente em um domínio de gerenciamento do VCF. Neste documento, vamos focar na parte do MetroCluster e indicar outras documentações conforme as etapas de implantação.

image:vmw-vcf-vmsc-mgmt-mcc-001.png["Domínio de gerenciamento VCF com vMSC, largura = 500"]



[[introduction]]
== Introdução

Nesta solução, demonstraremos como implementar um domínio de gerenciamento VCF estendido com o ONTAP MetroCluster como principal datastore. O MetroCluster permite implantar uma solução de alta disponibilidade para todas as cargas de trabalho em execução no cluster ONTAP. Se for necessário implantar uma solução de alta disponibilidade específica para cargas de trabalho, considere usar o SnapMirror active sync (SAN e NAS). O SnapMirror active sync (SAN) opera no nível de grupo de consistência, enquanto o SnapMirror active sync (NAS) opera no nível da SVM. Para mais informações, consulte link:vmw-vcf-vmsc-mgmt-smas.html["Configure um cluster estendido para um domínio de gerenciamento VCF usando o SnapMirror Active Sync (SAN e NAS)"].



[[prerequisites]]
== Pré-requisitos

Este cenário requer os seguintes componentes e configurações:

* Configuração ONTAP MetroCluster suportada
* Máquina virtual de storage (SVM) configurada com o protocolo de storage preferencial.
* A interface lógica (LIF) foi criada para transportar o tráfego de storage e está associada à SVM.

[[deployment-steps-for-greenfield-vcf-management-domain-with-metrocluster]]
== Etapas de implantação para o domínio de gerenciamento VCF Greenfield com MetroCluster

Para implantações Greenfield (novas implantações sem nenhum componente VCF existente), a ferramenta VCF Installer é usada para implantar o domínio de gerenciamento. VMFS em FC e NFSv3 são suportados nesse cenário.

No caso de VMFS em FC, consulte link:vmw-vcf-mgmt-principal-fc.html["Domínio de gerenciamento VCF com datastore VMFS baseado em FC no ONTAP como principal storage"] para mais informações. Para NFSv3, consulte link:vmw-vcf-mgmt-principal-nfs.html["Domínio de gerenciamento VCF com datastore NFSv3 no ONTAP como principal storage"] para mais informações.



[[deployment-steps-for-brownfield-vcf-management-domain-with-metrocluster]]
== Etapas de implantação para o domínio de gerenciamento do VCF brownfield com o MetroCluster

Uma implantação brownfield é um cenário em que você tem um ambiente vSphere existente e deseja convergi-lo como um domínio de gerenciamento VCF.

Para iSCSI, NVMe-oF e NFSv4.1, é necessário configurá-lo com o vCenter (de preferência com o ONTAP tools) e, posteriormente, usar a ferramenta de instalação do VCF para convergir para o domínio de gerenciamento. Para mais informações, consulte link:vmw-vcf-mgmt-vmfs.html["Convergência do vCenter com datastore VMFS"] e link:vmw-vcf-mgmt-nfs.html["Convergência do vCenter com o datastore NFS"].
