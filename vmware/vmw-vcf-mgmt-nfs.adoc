= Fluxo de trabalho de implantação para convergir a instância do servidor vCenter para o domínio de gerenciamento VCF com datastores NFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Integre um cluster vSphere existente com NetApp ONTAP NFS datastores a um domínio de gerenciamento do VMware Cloud Foundation. Você revisará os requisitos de configuração, implantará as ONTAP tools e provisionará os NFS datastores, além de usar a VCF Installer Tool para validar e usar seus componentes existentes, implantar os novos componentes necessários e configurar a plataforma.

Este fluxo de trabalho também é aplicável se os datastores ONTAP NFS 4.1 forem usados como storage primário para o domínio de gerenciamento do VCF.

Para uma visão geral do processo de convergência, consulte a documentação da VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convertendo a infraestrutura virtual existente para um VCF"].
