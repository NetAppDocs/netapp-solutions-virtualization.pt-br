[role="lead"]
Neste caso de uso, descrevemos o procedimento para configurar um cluster estendido para o domínio de carga de trabalho do VMware Cloud Foundation (VCF) usando o ONTAP MetroCluster com FC, iSCSI, NVMe-oF, NFSv3 ou NFSv4.1 como datastore primário. O VCF oferece flexibilidade nas opções de implantação com base nas suas necessidades. A ferramenta VCF Ops é usada para implantar um novo domínio de carga de trabalho do VCF ou importar um ambiente vSphere existente para um domínio de carga de trabalho do VCF. Neste documento, vamos focar na parte do MetroCluster e indicar outras documentações conforme as etapas de implantação.

image:vmw-vcf-vmsc-viwld-mcc-001.png["Domínio de carga de trabalho VCF com vMSC, width=500"]



[[introduction]]
== Introdução

Nesta solução, demonstraremos como implementar um domínio de carga de trabalho VCF estendido com o ONTAP MetroCluster como principal datastore. O MetroCluster permite implantar uma solução de alta disponibilidade para todas as cargas de trabalho em execução no cluster ONTAP. Se for necessário implantar uma solução de alta disponibilidade específica para cargas de trabalho, considere usar o SnapMirror active sync (SAN e NAS). O SnapMirror active sync (SAN) opera no nível de grupo de consistência, enquanto o SnapMirror active sync (NAS) opera no nível de SVM. Para mais informações, consulte link:vmw-vcf-vmsc-viwld-smas.html["Configure um cluster estendido para um domínio de carga de trabalho VCF usando o SnapMirror Active Sync (SAN e NAS)"].



[[prerequisites]]
== Pré-requisitos

Este cenário requer os seguintes componentes e configurações:

* Configuração ONTAP MetroCluster suportada
* Máquina virtual de storage (SVM) configurada com o protocolo de storage preferencial.
* A interface lógica (LIF) foi criada para transportar o tráfego de storage e está associada à SVM.

[[deployment-steps-for-greenfield-vcf-workload-domain-with-metrocluster]]
== Etapas de implantação para um domínio de carga de trabalho VCF Greenfield com MetroCluster

Para implantações Greenfield (novas implantações sem nenhum componente VCF existente), a ferramenta VCF Ops é usada para implantar o domínio de carga de trabalho. VMFS em FC e NFSv3 são suportados nesse cenário.

No caso de VMFS em FC, consulte link:vmw-vcf-viwld-principal-fc.html["Domínio de workload VCF com datastore VMFS baseado em FC no ONTAP como principal storage"] para mais informações. Para NFSv3, consulte link:vmw-vcf-viwld-principal-nfs.html["Domínio de carga de trabalho VCF com datastore NFSv3 no ONTAP como principal storage"] para mais informações.



[[deployment-steps-for-brownfield-vcf-workload-domain-with-metrocluster]]
== Etapas de implantação para o domínio de carga de trabalho VCF Brownfield com o MetroCluster

Uma implantação brownfield é um cenário em que você tem um ambiente vSphere existente e deseja importá-lo como um domínio de carga de trabalho do VCF.

Para iSCSI, NVMe-oF e NFSv4.1, é necessário configurá-lo com o vCenter (de preferência com o ONTAP tools) e, posteriormente, usar a ferramenta VCF Ops para importá-lo como um domínio de workload. Para mais informações, consulte link:https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/building-your-private-cloud-infrastructure/working-with-workload-domains/import-an-existing-vcenter-to-create-a-workload-domain.html["Importe um vCenter existente para criar um domínio de carga de trabalho"].
