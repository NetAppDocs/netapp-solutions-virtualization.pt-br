= Fluxo de trabalho de implantação para convergir instâncias do servidor vCenter para o domínio de gerenciamento do VCF com datastores VMFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Converja um cluster vSphere existente com datastores VMFS do NetApp ONTAP para um domínio de gerenciamento do VMware Cloud Foundation. Você revisará os requisitos de configuração, implantará as ONTAP tools e provisionará datastores VMFS, além de usar a ferramenta VCF Installer para validar e usar seus componentes existentes, implantar os novos componentes necessários e configurar a plataforma.

Este fluxo de trabalho também é usado para utilizar quaisquer datastores VMFS suportados como storage primário para o domínio de gerenciamento do VCF.

Para obter uma visão geral do processo de conversão, consulte a documentação da VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convertendo a infraestrutura virtual existente para um VCF"].
