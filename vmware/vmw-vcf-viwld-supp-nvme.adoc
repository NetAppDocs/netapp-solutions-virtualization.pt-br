[role="lead"]
Comece adicionando datastores NVMe/TCP vVols como armazenamento suplementar para um domínio de carga de trabalho do VMware Cloud Foundation (VCF). Você revisará os requisitos de implantação, configurará SVMs e LIFs habilitados para NVMe/TCP, configurará a rede do host vSphere e implantará o datastore NVMe/TCP vVol.
